# Запуск и демонстрация

## Запуск

Нужен Node.js 20.19+ или 22.12+ (требование Vite 8).

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173). Ключи не нужны: всё ниже работает локально. Картинка по тексту и «The Stranger» включаются только при наличии ключей (см. [TOOLS.md](TOOLS.md) и `.env.example`).

Проверки:

```bash
npm test
```

```bash
npm run build
```

Если демо-дни изменились или пропали: **Settings → Restore demo days**. Вернутся все шесть дней с фотографиями.

## Сценарий видео (около 3 минут)

1. **Проблема (15 с).** Лендинг: «A darkroom for the person you were». Фото и текст хранят факты, а атмосфера дня теряется.
2. **Ввод дня (30 с).** **＋ → Save a day:** текст, фото, песня. Если загрузить свой аудиофайл, bpm и энергия измерятся на устройстве. Покажите «what we noticed» и название папки из 3–7 слов.
3. **Открытка (40 с).** Откройте любимый день (**Memories → пикник**). Открытка 4:5: фото меняются в ритме песни. Нажмите **Listen**, чтобы песня и картинка пошли вместе.
4. **«Почему так» (30 с).** Панель справа: коллаж победил импрессионизм с небольшим отрывом. Причины: «7 people → frames overlap», «128 bpm → each photo stays 4 beats», «major → clearer colours». Раскройте «Constant / Variable».
5. **Голос (20 с).** **Read it aloud**: название подсвечивается, фразы идут субтитрами, музыка становится тише. Затем покажите ночной день: голос тише, медленнее и ниже.
6. **Лента (20 с).** **Memories → Side by side** (`#/feed`): шесть дней рядом. Рамка одна, внутри шесть разных техник, палитр и ритмов.
7. **Папка дня (15 с).** Внизу страницы дня **Download the day folder**. Откройте ZIP: `story.txt`, `photos/`, `song.json` (без аудио), `memory.png`, `memory.json`, `voice.json`.
8. **Финал (10 с).** Всё работает без сети и ключей. Слова пользователя не переписываются, голоса только синтезированные.
